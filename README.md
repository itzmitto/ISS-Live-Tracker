# ISS Live Tracker

A real-time ISS tracking website built with Kotlin, Ktor and Tailwind CSS.

The application displays live information about the International Space Station, including its coordinates, altitude, velocity and current position on a world map.

## Planned technologies

- Kotlin
- Ktor
- Gradle
- Tailwind CSS
- JavaScript
- REST API
- Leaflet
- OpenStreetMap

## Planned features

- Live ISS latitude and longitude
- ISS altitude
- ISS velocity
- Interactive world map
- Live ISS marker
- Automatic data refresh
- Orbit trail
- Tracking status
- Error handling
- Responsive interface
